You set a PSNR or a pointwise error bound, and that is the bound you get. Every byte counts toward the reported rate, and every error is measured on the decoder's actual output.

How it works

f32 field→CDF 9/7 wavelet→integer prediction→quantize→context-mixed rANS→stream
1Predict, then pay only for surprise

A wavelet concentrates the field's energy. Per-band integer predictors and a deadzone quantizer then leave small residuals. Where they're needed, a correction stream enforces the pointwise bound. An encoder portfolio also tries Tucker, SZ-style interpolation and tensor-train candidates, and it keeps whichever stream is smallest.

2Learned contexts, integer arithmetic

Symbol probabilities come from hand-designed contexts or from a small integer MLP with an adaptive APM stage. The MLP is integer-only from end to end, so every machine computes the same probabilities. That makes the range coder's output, and the decoded field, identical down to the last bit.

3Streams that carry their decoder

A stream can embed its own decoder as a verified integer program in the tang IR. Each consumer compiles it for its backend, whether that's a GPU kernel, WGSL in the browser, or native Rust. The format can then change without breaking old readers.

use cram_codec::{codec::ErrorBound, gpuwav3::{decode3_box, encode3_f32, Gpu3Config}};

// encode at 80 dB PSNR; decode the whole box, same bits on CPU and GPU
let cfg = Gpu3Config::new(ErrorBound::Psnr(80.0));
let (stream, _stats) = encode3_f32(&field, &[nz, ny, nx], &cfg, 8);
let out = decode3_box(&stream, [0; 3], [nz, ny, nx], 8)?;
